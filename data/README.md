## Data Sources

Both files were manually exported from the Central Bank of Nigeria's official statistics pages, since the data renders dynamically via JavaScript (not directly scrapable).

**Exchange Rate:**
- Source: https://www.cbn.gov.ng/rates/ExchRateByCurrency.html
- Method: "Export to Excel" button on the page
- Coverage: December 2, 2024 – September 4, 2026 (daily)

**Inflation Rate:**
- Source: https://www.cbn.gov.ng/rates/inflrates.html
- Method: "Export to Excel" button on the page
- Coverage: January 2003 – July 2026 (monthly)

To reproduce this project, visit both pages, export the data, and save the files as `exchange_rates.xlsx` and `inflation_rates.xlsx` in this folder.
